Test steps · please do this for CareerViet

Five steps

1

On CareerViet, create a test job

  • Put a job code at the end of the job title.
    Example: [Dist 1 – HCM] Junior Career Advisor (26373)
  • You can use your own job number. Letters + numbers (like EZVI001) are also OK.
  • Set the email that receives applications to vi-careerviet@ezhire.asia
  • If CareerViet allows more than one email, you can keep your usual email too.
2

On EZHire staging, create the same job

  • Open the job. Click the Synced with Job Board tab (it is a tab, not a button) → Edit → + Add Job Board.
  • Job Applied Source: CareerViet
  • Job Code: 26373 (the code only, without brackets)
  • Click Add.
① Open the job → click the tab ② Click Edit ③ Click + Add Job Board ④ Select CareerViet, enter the code, click Add
The code must be exactly the same on CareerViet and in EZHire.
3

Apply to your test job once

Back on CareerViet, apply with a dummy name and a dummy CV. We only need one real notification email from CareerViet.

4

Wait a few minutes, then check EZHire

Open Talent Pool (or Selection Process) on EZHire staging. Your test candidate should appear with a CareerViet tag.

5

Tell us in the chat

Let us know the result — or if the candidate does not appear after about 10 minutes. We will check together.

Before you start

Good to know

Staging site

Use stg.ezhire.asia. Your browser asks for a username and password first — they were shared in the team chat.

Dummy data only

Use a dummy name and CV so no real candidate data goes to staging.

Nothing changes on CareerViet

EZHire only reads the notification email. Your usual email keeps working.
